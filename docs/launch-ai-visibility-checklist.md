# ArchLab launch — SEO & AI-visibility checklist

Research finding that drives this list: when asked "best AI sketch-to-render tools",
ChatGPT cited **Reddit threads and listicle blogs** as its sources, and ArchLab
appeared in **neither Google nor LLM answers**. The new domain has ~0 authority, so
SEO is a 3–6 month build — the items below are how you get *launch* traffic and start
showing up in AI answers now.

## Already done on-site (stages 1–4)
- [x] Keyword-targeted titles/H1s (ai for architects, architectural rendering, sketch to render)
- [x] Dedicated `/sketch-to-render` product page (primary SEO target)
- [x] Structured data: Organization, SoftwareApplication, FAQPage, BlogPosting
- [x] Canonical URLs, Open Graph + Twitter cards, geo meta (Arad, RO)
